How does film analysis work? (algorithm overview)

All film types: DPI is read from image metadata (or you enter it manually) → crop → your marks are scaled to full image resolution → pixel distances convert to mm using DPI ÷ 25.4.

Field size: Four light lines + four radiation guides → image auto-rotates to straight edges → parallel scans perpendicular to each guide within the configured band width (mm) find radiation edges (yellow dots) → perpendicular shift per side (A/B/G/T) → reported match = max shift.

Collimator / Gantry: Your circle defines the scan path → brightness sampled around circumference → radiation bands found → opposite pairs form central lines → intersections define radiation isocenter → displacement and wobble diameter in mm.

Open full step-by-step algorithm in Help ↗

How are dose results calculated? (formulas)

MQ = Mraw × Ktp × Kpol × Ks × phantom factor

Dw,Q(zref) = MQ × N × Kq  |  Dw,Q(zmax) = Dw,Q(zref) / TMR

Symmetry = max/min × 100  |  Flatness = max(3 points)/min(3 points) × 100  |  D10 = Md10/Mdmax × 100

All TRS-398 and QA deviation formulas in Help ↗

General Information





Absolute Dose


Ktp (Temperature & Pressure Correction)

TRS398 Formula:
Ktp =
(273.2 + T) × P0
(273.2 + T0) × P
Where:
• T = measured temperature (°C)
• T0 = 20°C (reference temperature)
• P = measured pressure (hPa)
• P0 = 1013.25 hPa (reference pressure)


Kpol (Polarity Correction)

📋 Using previous values
TRS398 Formula:
Kpol =
|M+| + |M-|
2 × |M+|
Where:
• M+ = positive polarity reading
• M- = negative polarity reading


Ks (Ion Recombination Correction)

TRS398 Formula:
Ks = a0 + a1(M1/M2) + a2(M1/M2)2
Where:
• M1, M2 = charge readings
• V1, V2 = applied voltages
• a0, a1, a2 = coefficients from TRS398 table based on V1/V2 ratio
📋 TRS398 Reference: Table 8.1 provides a0, a1, a2 coefficients for different V1/V2 ratios. The coefficients depend on the voltage ratio and chamber type.
