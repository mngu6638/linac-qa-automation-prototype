# Screenshots

All screenshots are located in the `screenshots/` directory at the repository root. They were captured from the prototype running with **synthetic demo data only**.

## Available Screenshots

| File | Demonstrates |
|------|-------------|
| `Homepage.png` | Central dashboard with navigation to all modules, organization branding area, and feature summary. |
| `QA_Schedule.png` | Monthly QA scheduling with per-LINAC session cards, status tracking, and performer assignment. |
| `Film_Analysis.png` | Field-size mismatch estimation, collimator star-shot-style analysis, and gantry star-shot-style analysis results with annotated overlays. |
| `Dose_Calculator_TRS398.png` | TRS-398-oriented dose calculation workflow showing correction factors, corrected charge, and absorbed dose with inline formula references. |
| `Equipment_management.png` | LINAC and device inventory dashboard with service reports, downtime tracking, and filtering. |
| `Settings.png` | Centralized configuration for QA tests, physics parameters, dosimeters, user accounts, and organization settings. |

## Safety Rules for Screenshots

Screenshots included in this repository must not contain:

- real hospital names or logos,
- real staff names or email addresses,
- real patient data of any kind,
- real LINAC or chamber serial numbers,
- real commissioning, CAT, or beam data,
- identifiers linking to a specific clinical institution.

All screenshots should show synthetic demo data or be redacted before inclusion.
