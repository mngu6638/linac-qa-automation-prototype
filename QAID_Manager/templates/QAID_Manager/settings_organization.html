📋 Report Template Placeholders Reference

Use these placeholders in your DOCX template file. They will be automatically replaced with actual data when generating reports.

Basic Information Placeholders

Placeholder Description Example Output
{{LINAC_NAME}} The LINAC name Demo Linac A
{{LINAC_SERIES_NUMBER}} The LINAC series number SN123456
{{DATE_PERFORMED}} The QA date (YYYY-MM-DD format) 2025-07-30
{{PERFORMED_BY}} The person who performed the QA John Doe
{{STATUS}} The QA status Completed

Detailed Date/Time Placeholders

Placeholder Description Example Output
{{QA_PERFORMED_DATE_DD}} Day of the month (01-31) 30
{{QA_PERFORMED_DATE_MM}} Month (01-12) 07
{{QA_PERFORMED_DATE_YYYY}} Year (YYYY) 2025
{{QA_PERFORMED_DATE_HHMM}} Time in HH:MM format 14:30
{{QA_PERFORMED_BY_USER}} The user who performed the QA John Doe

Individual Test Placeholders (All 20 Tests)

Each test has 4 placeholders: VALUE, NAME, STATUS, and TOLERANCE

Format Pattern:

  • {{TEST_XX_VALUE}} - Test value (e.g., 1.25)
  • {{TEST_XX_NAME}} - Test name
  • {{TEST_XX_STATUS}} - Pass/Fail status (Đạt/Không đạt)
  • {{TEST_XX_TOLERANCE}} - Tolerance value (e.g., ±1.0)
