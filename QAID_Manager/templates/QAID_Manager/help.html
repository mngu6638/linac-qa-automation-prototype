    1. Getting Started

    Login

    1. Navigate to the login page
    2. Enter your username and password
    3. Click "Login"
    4. You will be redirected to the home page

    Change Password

    1. Click "Change Password" in the navigation bar
    2. Enter your current password
    3. Enter your new password twice
    4. Click "Change Password"

    Navigation

    The navigation bar at the top of each page contains the following links:

    • Home: Main dashboard and module links
    • QA Schedule: View and manage monthly QA schedules
    • Equipment Management: Service and breakdown reports for LINACs and devices
    • Statistics: QA trend review, LINAC comparison, and CSV export
    • Settings: Configure LINACs, dosimeters, tests, and other parameters (admin)
    • Change Password: Update your account password
    • Logout: Sign out of the system

    Recommended workflow for new users

    1. Confirm your account and change your password if required.
    2. Open QA Schedule, find your assigned LINAC, and click Performing QA (or Resume QA if a draft exists).
    3. On the QA Entry form, complete mechanical and isocenter tests, then use the film Run … Analysis wizards for field size, collimator, and gantry.
    4. Use the integrated Dose Calculation section for beam tests, then click Confirm Dose Calculation to populate results.
    5. Review pass/fail indicators and click Submit to finalize (or Save & Resume Later for a draft).
    6. After monthly QA is complete, use Statistics for department trend review and Reports to generate documentation.

    5. Film Analysis (Guided Wizard)

    On the QA Entry form, each film section (Field size, Collimator, Gantry) has a single Run … Analysis button that opens a guided wizard. The wizard walks you through upload, crop/rotate, and center/line marking, then runs analysis automatically. Use Re-analyze to run the wizard again for that film type.

    How film analysis works — step-by-step algorithm (plain language)

    This section describes exactly what the software does with your film image to produce the reported numbers. No programming knowledge is required.

    A. Common steps for all film types

    Step 1 — Upload and read image scale (DPI)
    The software opens your uploaded image file (PNG, JPG, or TIFF) and looks for embedded scanner resolution metadata (dots per inch, DPI).
    • If DPI is found and greater than zero, that value is stored.
    • If no DPI metadata exists, you must enter DPI manually before continuing; otherwise analysis cannot convert pixels to millimetres.
    • Accepted DPI is limited to the range 75–1200 to reject unrealistic values.
    Pixel size is then calculated as:
    pixels per mm = DPI ÷ 25.4
    Example: 300 DPI → 300 ÷ 25.4 ≈ 11.81 pixels per mm.
    Step 2 — Crop the region of interest
    You select a rectangular crop on the displayed image. The software saves only that cropped region for analysis. Optional rotation during crop aligns the film visually before marking.
    Step 3 — Convert screen marks to true image coordinates
    Lines and circles you draw on screen may be shown at a different display size than the actual image file. The software scales your click positions back to the full-resolution cropped image before any measurement.

    B. Field size analysis (light field vs radiation field)

    Step 4 — Collect your line marks
    You draw four light field lines and four radiation edge guide lines (two clicks per line: start and end). The software requires exactly four of each, paired in matching order around the field.
    Step 5 — Auto-rotate to a straight axis-aligned frame
    From your four light-field lines, the software estimates the average orientation of the field and rotates the entire image so the field edges become as close as possible to horizontal and vertical. This angle correction (shown on the result image in degrees) removes tilt from the film placement and makes left/right/top/bottom comparisons consistent.
    Step 6 — Pair each light line with its radiation guide
    For each side of the field, the software matches light lines to radiation guide lines that belong to the same edge (left, right, top, or bottom) using position and angle similarity.
    Step 7 — Detect the true radiation edge from image brightness
    For each radiation guide line, the software does not simply use your click as the final edge. Instead it:
    1. Finds the most common background grey level in the cropped image.
    2. Several parallel scan lines are offset perpendicular to each radiation guide, spanning only the configured band width in millimetres (default 8 mm; guide centred — 4 mm each side). Along each parallel line the software finds one radiation edge point (yellow dot on the result image). Set band width in Film Analysis Parameters.
    3. On each profile, locates the point where brightness rises to the configured field size detection threshold (default 30%) of the way from the darkest to brightest value along that profile — this is treated as the radiation field boundary. Staff can change this by editing the Film Analysis Parameters row in Settings → Physics Parameters.
    4. Collects many such edge points, removes outliers, and fits a straight radiation edge line constrained to be parallel to the paired light-field line (physically, radiation and light edges on one side should be parallel).
    Step 8 — Measure shift on each side (A, B, G, T)
    For each field side, the software measures the shortest perpendicular distance (in pixels) between the detected radiation line and the corresponding light-field line. Distances are averaged per side, then converted to millimetres:
    shift (mm) = shift (pixels) ÷ (DPI ÷ 25.4)
    • A = left-side shift (mm)
    • B = right-side shift (mm)
    • G = gun-side (top) shift (mm)
    • T = target-side (bottom) shift (mm)
    Step 9 — Report field size match
    The value written to the Film Checks table is the maximum of the four side shifts:
    Field size match (mm) = max(A, B, G, T)
    The result image overlays green (light) and red (radiation) lines, yellow edge sample points, side labels, and the angle correction.

    C. Collimator and gantry isocenter analysis (starshot / circle film)

    Collimator and gantry analyses use the same mathematical procedure; only the film type and session data differ.

    Step 4 — Define analysis circle
    You click the mechanical isocenter and drag to set a circle radius. The circle should pass through the radiation marks (starshot pattern) at a representative radius.
    Step 5 — Sample brightness around the circle
    The software converts the image to greyscale and reads pixel brightness at many points along the circle circumference (from 0° to 420° so peaks are not split at the wrap-around). This produces a radial profile of darkness vs angle.
    Step 6 — Find radiation bands (peaks)
    Valleys and peaks in the radial profile identify dark radiation bands. At least six bands are required. Nearby detections within about 30° are merged; band positions are refined using depth-weighted averaging. Up to eight strongest bands are kept.
    Step 7 — Build central lines through opposite bands
    Opposing band pairs (approximately 180° apart) are connected through the mechanical center, forming central axis lines through the starshot pattern.
    Step 8 — Find radiation isocenter
    The software calculates where these central lines cross. Each intersection is a candidate radiation isocenter point. The final radiation isocenter is the center of the smallest circle that encloses all intersection points (minimum enclosing circle algorithm).
    Step 9 — Displacement and wobble diameter
    Displacement from mechanical center to radiation isocenter:
    displacement (pixels) = √[(xrad − xmech)² + (yrad − ymech)²]
    displacement (mm) = displacement (pixels) ÷ (DPI ÷ 25.4)
    The circle diameter (wobble) is the diameter of the minimum enclosing circle around intersection points, also converted to mm. For collimator QA, diameter < 1.0 mm is treated as acceptable.
    Step 10 — Populate QA form
    Collimator: offset (mm) and wobble diameter (mm). Gantry: circle diameter (mm). Values auto-fill in Film Checks when analysis completes.

    Guided wizard steps (all film types)

    1. Upload: Select the film image (PNG, JPG, TIFF). DPI is read automatically; enter it manually if needed. Click Continue.
    2. Crop: Drag to select the region of interest. Rotate if needed. Click Next.
    3. Center:
      • Field size: Draw 4 radiation field edge lines and 4 light field lines (click twice per line).
      • Collimator / Gantry: Click to set circle center, drag to set radius.
      Click Finish — analysis runs automatically.
    4. Results: The annotated result image appears on the QA form and values auto-fill in the Film Checks section.

    Field Size Analysis

    Click Run Field Size Analysis. In the Center step, switch between Radiation edges and Light field lines before drawing each set of four lines. Click twice per line (start point, end point); a dashed preview line follows the cursor after the first click. Use Clear group to remove all lines in the active group, or Undo to remove the last line. Results show field size shift in millimeters and populate the Film Checks table automatically.

    Collimator Isocenter Analysis

    Click Run Collimator Analysis. After the wizard completes, optional View Radial Profile and Multi-Radius Comparison buttons may appear for detailed review.

    Gantry Isocenter Analysis

    Click Run Gantry Analysis. The wizard uses the same circle-marking step as collimator. Results show gantry isocenter circle diameter in millimeters.

    Tips for Film Analysis

    • Expand How film analysis works above for the full mathematical workflow in plain language
    • Use high-resolution images (300 DPI or higher recommended; enter DPI manually if not detected)
    • Ensure good contrast between radiation field and background
    • Draw lines as close to field edges as possible
    • If DPI is not detected, enter it manually (check scanner settings)
    • Use Re-analyze to upload a new film and repeat the full wizard
    • Staff users can expand Advanced (dev) to access individual Import / Crop / Center / Analyze controls

    6. Dose Calculation

    Access Dose Calculator

    The Dose Calculator is integrated into the QA Entry form. Scroll to the "Dose Calculation" section.

    How dose values are calculated — formulas and definitions

    All absolute dose corrections follow IAEA TRS-398. Relative dose and beam-quality checks use measured ion-chamber readings compared to commissioning (CAT) baselines stored for each LINAC and energy.

    1. Environmental correction — Ktp (temperature & pressure)

    Ktp = [(273.2 + T) × P0] / [(273.2 + T0) × P]
    T = measured temperature (°C); P = measured pressure (hPa). T0 and P0 come from the selected dosimeter calibration record (defaults: 20 °C and 1013.25 hPa).

    2. Polarity correction — Kpol

    Kpol = (|M+| + |M−|) / (2 × |M+|)
    M+ and M− are chamber readings at positive and negative polarity (nC).

    3. Ion recombination correction — Ks

    Ks = a0 + a1 × (M1/M2) + a2 × (M1/M2)²
    M1, M2 are readings at voltages V1 and V2. Coefficients a0, a1, a2 are looked up from the Physics Parameters database for your voltage ratio V1/V2 (TRS-398 Table 8.1 values).

    4. Corrected chamber reading — MQ

    MQ = Mraw × Ktp × Kpol × Ks × fphantom
    Mraw = raw electrometer reading (nC). fphantom = solid phantom correction factor (1.0 for water phantom; user-entered when solid phantom is selected).

    5. Beam quality — TPR and Kq

    TPR20,10 = 1.2661 × PDD20,10 − 0.0595
    PDD20,10 is loaded from LINAC commissioning (CAT) data. Kq is interpolated from the kQ Photon Beams table for your detector type and calculated TPR.

    6. Absorbed dose at reference depth — Dw,Q(zref)

    Dw,Q(zref) = MQ × N × Kq
    N = dosimeter calibration factor ND,w (Gy/nC) from the selected detector. Result is displayed in cGy.

    7. Absorbed dose at zmax

    Dw,Q(zmax) = Dw,Q(zref) / TMR
    TMR = tissue–maximum ratio for the selected LINAC energy (from CAT data).

    8. Symmetry (crossline and inline)

    Symmetrycrossline (%) = [max(MLeft, MRight) / min(MLeft, MRight)] × 100
    Symmetryinline (%) = [max(MGun, MTar) / min(MGun, MTar)] × 100
    When CAT commissioning symmetry exists, the value shown for QA comparison is percent deviation from baseline: |measured − CAT| / CAT × 100.

    9. Flatness (three-point method)

    Flatness (%) = [max(a, b, c) / min(a, b, c)] × 100
    Crossline uses MLeft, MRight, Mmid. Inline uses MGun, MTar, Mmid. Compared to CAT flatness using |measured − CAT| / CAT × 100 when baseline exists.

    10. Output factor and wedge factor

    Output factor = Mmid / Mref     (FS20×20 relative to FS10×10 reference)
    Wedge factor = Mwedge / Mref
    When CAT baselines exist, QA stores |measured ratio − CAT ratio| / CAT ratio × 100 as the percent deviation.

    11. Beam energy stability (D10)

    D10 (%) = (Md10 / Mdmax) × 100
    This is the measured percentage depth at 10 cm relative to dmax. QA pass/fail compares the deviation from the commissioning D10 value.

    12. MU linearity — coefficient of determination R²

    For each entered MU level (10, 30, 50, 100, 300, 500), the software plots charge (nC) vs MU and fits a straight line y = mx + b using least squares:

    slope m = [Σ(xy) − n·x̄·ȳ] / [Σ(x²) − n·x̄²]     intercept b = ȳ − m·x̄
    R² = 1 − [Σ(yi − ŷi)²] / [Σ(yi − ȳ)²]
    x = MU, y = charge (nC), ŷi = predicted charge on the fitted line. Test passes when R² > 0.99 (at least two MU points required).

    13. Values written to Beam Tests after Confirm Dose Calculation

    After you click Confirm Dose Calculation, the calculator populates beam test fields using:

    • Absolute dose: percent deviation of measured Dw,Q(zmax) from the CAT baseline dose.
    • Symmetry / flatness / output / wedge: percent deviation formulas above (displayed as difference% (measured%) on the QA form).
    • MU linearity: R² value directly.
    • Energy stability D10: percent deviation of measured D10 from CAT D10.

    Absolute Dose Calculation

    1. Select Parameters:
      • Select LINAC (auto-filled if from schedule)
      • Select Energy (6MV, 10MV, etc.)
      • Select Detector (dosimeter)
      • Select Phantom type (Solid or Water)
      • Select Setup: SAD (default) or SSD. In SSD mode a PDD(zref) field appears, auto-loaded from the LINAC's CAT D10 value but editable for manual override
    2. Enter Raw Measurement:
      • Enter raw measurement value in nC (nanocoulombs)
    3. Enter Environmental Conditions (for Ktp):
      • Enter Temperature (°C)
      • Enter Pressure (hPa)
      • Ktp is calculated automatically
    4. Enter Polarity Measurements (for Kpol):
      • Enter M+ (positive polarity reading)
      • Enter M- (negative polarity reading)
      • Kpol is calculated automatically
    5. Enter Recombination Measurements (for Ks):
      • Enter M1 (measurement at voltage V1)
      • Enter M2 (measurement at voltage V2)
      • Enter V1 and V2 (voltages)
      • Or enter V1/V2 ratio directly
      • System fetches Ks coefficients from database
      • Ks is calculated automatically
    6. View Results:
      • MQ (corrected charge) is calculated automatically
      • Dw,Q(zref) is calculated from MQ and beam-quality data
      • Dw,Q(zmax) is calculated: in SAD mode using PDD(20/10); in SSD mode using 100 × Dw,Q(zref) / PDD(zref)
      • All correction factors are displayed

    Relative Dose Measurements

    1. Enter Mref (reference measurement at FS10x10)
    2. Enter measurements for symmetry and flatness:
      • MLeft, MRight (for crossline)
      • MGun, MTar (for inline)
      • Mmid (midpoint)
    3. Enter other measurements as needed:
      • Mwedge (wedge factor)
      • Mdmax, Md10 (for energy determination)
    4. System calculates:
      • Symmetry (inline and crossline)
      • Flatness (inline and crossline)
      • Output factor
      • Wedge factor
      • Beam energy (D10)

    MU Linearity Calculation

    1. Scroll to "MU Linearity" section in the Dose Calculator
    2. Enter charge measurements (in nC) for different MU values:
      • 10 MU
      • 30 MU
      • 50 MU
      • 100 MU
      • 300 MU
      • 500 MU
    3. System automatically:
      • Calculates linear regression (line of best fit)
      • Displays graph showing MU (X-axis) vs Charge (Y-axis)
      • Calculates R² value (coefficient of determination)
      • Shows Pass/Fail status (R² > 0.99 required)
    4. Results are displayed in real-time as you enter values

    Expand How dose values are calculated above for every formula used by the calculator (Ktp, Kpol, Ks, MQ, Dw,Q, symmetry, flatness, MU linearity R², and CAT deviations).

    Use Calculation Results

    1. Review all calculated values
    2. Click "Confirm Dose Calculation" button
    3. System auto-populates Beam Tests section:
      • Absolute dose deviation: difference% (measured%)
      • Energy stability D10: difference% (measured%)
      • Symmetry vs commissioning: difference% (measured%)
      • Flatness vs commissioning: difference% (measured%)
      • MU Linearity: R² value (test passes if R² > 0.99)
      • Output factor deviation: difference% (measured%)
    4. All results show the percentage difference from baseline, with the measured value in parentheses (italic and gray)
    5. Calculation is saved to database

    Load Previous Values

    When you select a LINAC, the system can load previous dose calculation values for the same LINAC:

    1. Select LINAC in dose calculator
    2. Click "Load Previous Values" (if available)
    3. Previous M+, M-, M1, M2, V1, V2 values are loaded

    8. Statistics

    The Statistics module is read-only. It helps physicists and QA leads review historical QA performance, compare LINACs, and identify tests that need attention. Open it from the navigation bar or home page.

    Filters (top of page)

    • View mode: Overview, Single Test Trend, All Tests for LINAC, Category Trends, or Beam Energy Trends
    • Date range: Presets (last 3/6/12 months, year to date, previous year) or custom dates
    • LINAC: One machine, multiple machines (Ctrl+click), or all active LINACs
    • Category / QA test / Beam energy: Shown depending on view mode
    • Click Apply filters after changing options; use Export CSV to download the current view

    View modes

    • Overview: Department dashboard — LINAC completion, missing-QA heatmap, charts, pending review, and collapsible matrix/detail tables
    • Single Test Trend: Main trend graph for one QA test with Warning and Action reference lines (from test tolerance settings), summary stats, and linked QA records
    • All Tests for LINAC: Mini-trend cards plus summary table for every test on one machine
    • Category Trends: Mini-trends for all tests in a category (mechanical, film, beam, etc.)
    • Beam Energy Trends: Mini-trends for beam tests at a selected energy

    Traffic-light classification

    Results are classified as Pass (within tolerance), Warning (beyond tolerance but within the test warning threshold), or Action (beyond warning threshold plus 0.5 units). Graph reference lines use the same Warning/Action definitions.

    Drill-down

    Click matrix cells, review-list rows, or mini-trend cards to open Single Test Trend for that test and LINAC. In Single Test Trend, you can adjust custom reference lines on the graph; lines update in real time as you edit values.

    10. Troubleshooting

    Common Issues

    Film Analysis - DPI Not Detected

    • Enter DPI manually in the upload form
    • Check scanner settings - DPI should be in image metadata
    • Common DPI values: 300, 600, 1200

    Film Analysis - Poor Edge Detection

    • Ensure good image contrast
    • Draw lines closer to actual field edges
    • Try adjusting line positions and re-analyzing
    • Use higher resolution images

    Dose Calculation - Missing Coefficients

    • Check that Physics Parameters are configured in Settings
    • Ensure Ks coefficients are entered for your voltage ratios
    • Verify detector calibration factors are set
    • Contact admin to add missing parameters

    QA Schedule - Cannot Assign Performers

    • Ensure users exist in the system (Settings → Users)
    • Check that you have permission to edit schedules
    • Try refreshing the page

    Report Generation Fails

    • Check that QA record has test results
    • Verify report template file is valid DOCX format
    • Check file permissions
    • Try generating without custom template first

    Values Not Auto-Populating

    • Film results populate automatically when the guided wizard completes successfully (no separate "Use Results" button)
    • For beam tests, click Confirm Dose Calculation after entering measurements
    • Check that analysis or dose calculation finished without an error message
    • Verify JavaScript is enabled in your browser

    Film Wizard — Cannot Proceed After Upload

    • Ensure a file is selected and DPI is detected or entered manually before clicking Continue
    • If crop step fails, re-upload the film and run the wizard again
    • For field size lines, draw exactly 4 radiation and 4 light lines before clicking Finish

    Statistics — Charts or Tables Missing

    • Click Apply filters after changing view mode or date range
    • Ensure QA records exist in the selected period
    • If graphs do not render after an update, refresh the page or clear browser cache (static assets may be stale)

    11. Software Updates

    Updates are delivered as a ZIP package. Your database and user data are preserved when you apply an update.

    How to Apply an Update

    1. Stop the QAID Manager server (and close the application if running as a desktop app).
    2. Obtain the update ZIP from your administrator and extract it (or use the provided updater script).
    3. If using update_app.bat (or update_app.ps1): place the ZIP in the same folder as the script and run it; the script will replace program files but keep your data folder (e.g. data), database, and config.
    4. If an integrity manifest file (update_package_manifest_v<version>.json) is present next to the ZIP, updater verifies SHA256 before applying files.
    5. If updating manually: copy the new executable and support files over your installation folder, but do not overwrite your data directory (or wherever your database and media are stored).
    6. Start the server (or application) again. Confirm the version on the Home page (under the main title and in the footer), Help, or About.
